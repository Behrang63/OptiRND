سامانه هوشمند ارزیابی و مدیریت ریسک پروژه‌های پژوهشی (پژوهشیار)
Pajoheshyar: AI-Driven R&D Risk Evaluation & Portfolio Management Platform
پژوهشیار یک پلتفرم نرم‌افزاری پیشرفته و هوشمند برای مدیریت ریسک، ارزیابی اقتصادی و پایش فرآیندی پروژه‌های تحقیق و توسعه (R&D) در صنایع بزرگ و سنگین (مانند فولاد، نفت و پتروشیمی) است. این سامانه با تلفیق مدل‌های ریاضی پیشرفته مانند شبیه‌سازی مونت‌کارلو (Monte Carlo)، ارزش در معرض ریسک (VaR)، نقشه‌برداری کارایی-عدم‌قطعیت (Efficiency-Uncertainty Mapping) و عامل‌های هوشمند (AI Agents)، زبان مشترک و قابل‌دفاعی میان مدیران R&D و هیئت‌مدیره ایجاد می‌کند.
🌟 ویژگی‌های کلیدی پلتفرم
عامل ارزیابی پیشینی (Ex-ante Evaluation Agent):
تحلیل عدم‌قطعیت‌های فنی، زمانی و مالی با شبیه‌سازی ۱۰,۰۰۰ سناریو.
محاسبه نرخ بازگشت سرمایه تعدیل‌شده با ریسک (Risk-Adjusted ROI) و شاخص VaR.
ماتریس‌بندی ۱۰ معیار کلیدی استراتژیک (ارزش‌ها و ریسک‌ها).
عامل پایش فرآیندی (Process-Monitoring Agent):
ردیابی خودکار انحرافات زمانی و بودجه‌ای در مایلستون‌های پروژه.
جانمایی پویای پروژه در یکی از ۴ ناحیه استراتژیک (Exploitation, Challenge, Desperation, Discretion).
صدور هشدارهای زودهنگام ریسک (Early Warning System).
عامل ارزیابی پسینی (Ex-post Value Agent):
اتصال به KPIهای خط تولید (کاهش ضایعات، کاهش توقف خط، بومی‌سازی).
تفکیک اثر واقعی R&D از متغیرهای مداخله‌گر محیطی با تحلیل رگرسیون تصادفی.
صدور گواهی ارزش‌آفرینی مالی قابل‌دفاع در شورای عالی سرمایه‌گذاری.
موتور RAG محلی و استخراج پیشرفته اسناد:
استخراج متون، جداول ساختاریافته و زیرنویس اشکال از پروپوزال‌های PDF/Word.
جستجوی هیبریدی محلی بدون وابستگی الزام‌آور به اینترنت یا سرویس‌های ابری.
معماری مقاوم و بدون کرش (Mock-First Fallback):
قابلیت اجرای ۱۰۰٪ کامل بخش‌های محاسباتی و UI حتی در صورت عدم اتصال به هوش مصنوعی (مبتنی بر Rule-based Fallbacks).
🛠️ پیش‌نیازها و راه‌اندازی در محیط مجازی (Virtual Environment)
۱. پیش‌نیازها
Python 3.10 یا بالاتر
Git
VS Code (پیشنهادی)
۲. ساخت و فعال‌سازی محیط مجازی
# کلون کردن مخزن
git clone https://github.com/your-username/pajoheshyar-ai-agents.git
cd pajoheshyar-ai-agents

# ساخت محیط مجازی
python -m venv venv

# فعال‌سازی محیط مجازی (در ویندوز)
venv\Scripts\activate

# فعال‌سازی محیط مجازی (در لینوکس/مک)
source venv/bin/activate

۳. نصب وابستگی‌ها
pip install --upgrade pip
pip install -r requirements.txt

🚀 نحوه اجرا و تست پروژه
اجرای اپلیکیشن وب (Streamlit)
streamlit run app.py

پس از اجرا، مرورگر خود را در آدرس http://localhost:8501 باز کنید.
اجرای تست‌ها درون VS Code / Terminal
جهت اطمینان از صحت محاسبات آماری و پایگاه داده بدون نیاز به وب:
pytest

اجرای اسکریپت تست کامل جریان داده (End-to-End Pipeline)
python scripts/test_pipeline.py

📂 ساختار مخزن (Repository Structure)
pajoheshyar-core/
├── config/             # تنظیمات YAML و آستانه‌های محاسباتی
├── core/               # موتور محاسباتی (مونت‌کارلو، دیتابیس، RAG و پارسر)
├── agents/             # عامل‌های هوشمند اصلی و فرعی (Sub-agents)
├── ui/                 # فرم‌ها، جداول st.data_editor و صفحات Streamlit
├── data/               # دیتابیس محلی SQLite و نمونه اسناد
├── tests/              # تست‌های واحد و یکپارچه‌سازی با pytest
├── scripts/            # اسکریپت‌های تست CLI در VS Code
├── SKILL.md            # دستورالعمل‌های توسعه با AI
├── ROADMAP.md          # نقشه راه توسعه
└── app.py              # نقطه ورود اصلی اپلیکیشن Streamlit
